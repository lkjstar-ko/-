📐클래스 정의하기

속성은 변수로, 메소드는 함수 형태로 정의합니다. 클래스 첫 글자는 보통 대문자로 써요.

class Dice:
    def __init__(self):       # 생성자: 인스턴스 만들 때 자동 실행
        self.value = 0     # 속성(데이터) 초기화

    def roll(self):           # 메소드(기능)
        import random
        self.value = random.randint(1, 6)
        return self.value

🎯인스턴스 생성하고 사용하기

dice1 = Dice()        # 인스턴스 생성 ← 클래스명()
print(dice1.value)    # 속성 사용 ← 인스턴스명.속성
print(dice1.roll())   # 메소드 호출 ← 인스턴스명.메소드()
📌 클래스를 한 번 정의하면 dice1, dice2, dice3 … 처럼 인스턴스를 여러 개 만들 수 있어요. 모두 같은 속성·메소드를 가집니다.

🖼️실습 · 이미지 처리 (PIL)

PIL(Python Imaging Library)로 이미지를 인스턴스로 만들고, 속성·메소드로 처리합니다. (이미지 파일이 필요해 구글 코랩 등에서 실행해요.)

from PIL import Image
img = Image.open('lighthouse.jpg')
print(img.size)   # (1200, 797) ← 크기 속성
print(img.mode)   # RGB ← 색상 모드 속성
img.rotate(50)                       # 회전 메소드
img.transpose(Image.FLIP_LEFT_RIGHT)  # 좌우 반전
img.filter(ImageFilter.BLUR)          # 흐림 필터
