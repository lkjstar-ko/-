🤖왜 기계학습이 필요할까?

국어·수학 성적의 평균을 구하는 프로그램은 규칙이 명확해서 그대로 코드로 옮기면 됩니다. 하지만 개와 고양이를 구분하는 규칙을 적어 보라고 하면? "귀가 뾰족하면 고양이"라고 쓰는 순간 귀가 접힌 스코티시폴드가 떠오르죠. 예외가 끝없이 나옵니다.

# 규칙을 쓸 수 있는 문제 → 전통적 프로그래밍
평균 = (국어 + 수학) / 2

# 규칙을 쓸 수 없는 문제 → 기계학습
if 귀가 뾰족하면: 고양이     # 스코티시폴드는?
elif 코가 길면: 개          # 페르시안 고양이는?
💡 한 줄 요약 — 사람이 규칙을 주면 전통적 프로그래밍, 사람이 데이터를 주고 컴퓨터가 규칙을 찾으면 기계학습!

🗂️ vs 📈  분류 vs 예측
답의 형태를 보세요.
이름으로 나오면 분류 (합격/불합격)
숫자로 나오면 예측 (점수 87점)
🗂️ vs 🔗  분류 vs 군집
정답을 알려 줬는지 보세요.
정답 이름표가 있으면 분류
정답 없이 스스로 묶으면 군집
👁️  인식은 언제?
다루는 데이터가 사진·소리·글이면 인식.
넓게 보면 분류의 한 종류예요.
🌧️  같은 주제도 유형이 갈린다
"비가 올까?" → 분류
"비가 몇 mm 올까?" → 예측
주제가 아니라 답의 형태가 기준!

🎯기계학습으로 풀 문제 정의하기

기계학습의 첫 단계는 코딩이 아니라 무엇을 해결할지 정하는 것입니다. 세 가지를 순서대로 정해 보세요.

1️⃣
문제 찾기
무엇이 불편한가?
해결하고 싶은 상황
2️⃣
유형 정하기
분류? 예측?
군집? 인식?
3️⃣
데이터 정하기
무엇을 모아야
답을 찾을 수 있나
📌 예시 — "급식 잔반을 줄이고 싶다"
→ 유형: 예측 (잔반량이라는 숫자를 맞힌다)
→ 데이터: 날짜 · 요일 · 메뉴 · 날씨 · 급식 인원 · 잔반량
→ 목표: 내일 잔반량을 예측해 배식량을 미리 조절한다
