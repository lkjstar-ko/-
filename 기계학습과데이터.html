🤖왜 기계학습이 필요할까?

국어·수학 성적의 평균을 구하는 프로그램은 규칙이 명시적이라 전통적 프로그래밍으로 충분합니다. 하지만 개와 고양이를 구분하거나 얼굴에서 감정을 읽는 일은 규칙을 일일이 적을 수 없어요. 기계학습은 사람이 규칙을 쓰는 대신, 데이터 속에 숨은 패턴을 스스로 찾아 모델을 만듭니다.

💡 한 줄 요약 — 사람이 규칙을 주면 전통적 프로그래밍, 사람이 데이터를 주면 기계학습! 그래서 기계학습에서는 "어떤 데이터를 주느냐"가 곧 모델의 성능이 됩니다.

🧹데이터 전처리

탐색에서 찾아낸 문제를 정리하는 단계입니다. 결측치(비어 있는 값)와 이상치(정상 범위를 크게 벗어난 값)를 처리하고, 속성마다 범위가 다르면 정규화로 맞춥니다.

df.isnull().sum()            # 속성별 결측치 수
df = df.dropna(axis=0)       # 결측치 행 삭제 (344 → 334)

df['sex'].unique()          # 'MALE','FEMALE','.' ← '.'이 이상치
df.drop(336, axis=0, inplace=True)

⭐핵심 속성 추출

모든 속성이 똑같이 중요하지는 않습니다. 상관계수(-1 ~ +1)로 두 속성이 함께 변하는 정도를 재서, 예측에 중요한 속성만 고릅니다.

sns.heatmap(df.corr(numeric_only=True), annot=True)
r ≈ +1

강한 양의 상관 — 함께 커진다
날개 길이–체질량 0.87

r ≈ 0

상관관계 없음
서로 무관한 속성

r ≈ −1

강한 음의 상관 — 반대로 간다
부리 깊이–체질량 −0.47

🎯 교과서의 결론 — 체질량은 날개 길이(0.87), 부리 길이와 상관이 높습니다. 따라서 부리 길이와 날개 길이가 체질량을 예측하는 핵심 속성이 됩니다.
